# LABS-PPM

Repositorio con laboratorios de Programación de Plataformas Móviles.

## Estructura

```text
LABS-PPM/
└── Lab4/
    └── app/
```
## Cómo ejecutar las aplicaciones

1. Entra a la carpeta del laboratorio. Ej `Lab4/`.
2. Abre el proyecto desde Android Studio.
3. Sincroniza *Gradle* antes de ejecutar la aplicación.
4. Ejecuta el proyecto desde Android Studio.

## Nota

Si se agregan más laboratorios en el futuro, se irán organizando como `Lab#/`.
